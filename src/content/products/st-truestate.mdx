## Overview

ST TrueState is an agentless configuration assurance platform designed to actively manage the state of your infrastructure. Powered by the Red Hat Ansible Automation Platform (RHAAP), it detects configuration drift and gives IT teams the control to decide whether to align systems back to the "gold standard" or update the baseline to reflect authorized changes.

## Key Features

**Drift Management** — Detects deviations from your defined baseline and provides the flexibility to either revert the drift or commit the change as the new configuration standard.

**Agentless Architecture** — Utilizes the Red Hat Ansible engine to execute checks and fixes remotely, eliminating the performance impact and management burden of installing agents.

**Full Change Visibility** — Tracks every configuration change: what, when, and where. It provides a clear audit trail for compliance, governance, and troubleshooting.

**Flexible Remediation** — Can be set to automatically revert unauthorized changes for security or be used to validate and merge drifts that improve the environment.

## The Strategic Advantage

TrueState turns configuration drift from a hidden risk into a managed process. It acknowledges that systems evolve, providing the visibility to distinguish between accidental "drift" and intentional improvements. This allows IT teams to maintain compliance without stalling innovation, instantly reverting unauthorized changes while easily adopting new configurations when necessary.
