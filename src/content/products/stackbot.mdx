## Overview

STackBot is a cloud-based automation service powered by RHAAP, delivered as a fully managed SaaS solution under the Red Hat CCSP program. It eliminates the need for expensive upfront licensing or dedicated automation servers, allowing users to pay strictly for the nodes they automate.

## Key Features

**Pay-Per-Use Efficiency** — A flexible licensing model where you only pay based on specific automation use cases and the number of nodes managed.

**Zero Infrastructure Overhead** — As a fully managed SaaS solution, there is no hardware to buy, patch, or maintain.

**Event-Driven Intelligence** — Seamlessly triggers automated remediation actions based on alerts from monitoring tools or tickets from ITSM systems.

**No Skillset Required** — Features a user-friendly interface that allows teams to schedule jobs and track status without needing deep coding expertise.
